# Steam Audio (UPM)

This repository represents a Unity Package Manager compatible version of Valve's Steam Audio library.

The original library can be found here: https://github.com/valvesoftware/steam-audio

## Supported Platforms

Steam Audio supports Windows (32 bit and 64 bit), Linux (32 bit and 64 bit), macOS, and Android (armv7, arm64, x86, x64) platforms.
